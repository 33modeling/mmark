# mmark — 마크다운 뷰어

파일이 지정되지 않아 도움말을 표시합니다.

## 사용 방법

1. **드래그 & 드롭** — 탐색기에서 `.md` 파일을 `mmark.exe` 위로 끌어다 놓으세요.
2. **파일 연결(권장)** — `.md` 파일 우클릭 → *연결 프로그램* → *다른 앱 선택* → `mmark.exe` 지정 후 *항상 이 앱 사용* 체크. 이후에는 더블클릭으로 바로 열립니다.
3. **명령줄** — `mmark.exe 문서.md`

## 기능

- GitHub 스타일 렌더링 (표, 체크박스, 취소선, 각주 포함)
- 코드 블록 문법 하이라이트
- 코드 블록 복사 버튼
- 문서 목차 사이드바와 본문 검색
- 라이트 / 다크 테마 — 기본은 시스템 설정을 따르고, 우상단 버튼으로 자동 → 라이트 → 다크 전환(선택은 저장됨)
- 파일 저장 시 자동 새로고침
- 인쇄/PDF용 스타일
- 문서 기준 상대 경로 이미지·링크 지원 (`.md` 링크는 이어서 렌더링)
- Mermaid 다이어그램 렌더링
- KaTeX 수식 렌더링 (`$$...$$`, `\(...\)`, 수식처럼 보이는 `$...$`)
- UTF-8 / UTF-16(BOM) / CP949(EUC-KR) 인코딩 자동 감지
- 한글 제목 앵커 및 문서 내 목차 링크 지원
- 문서에 포함된 스크립트는 실행 차단(CSP)

브라우저 탭을 닫으면 프로세스는 잠시 후 자동 종료됩니다.
